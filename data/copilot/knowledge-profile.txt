### 企業 AI 資安控制（深度實戰）
- 八層資安控制架構：網路架構 → IP Allowlist → Workspace Header → SSO/SCIM/RBAC → Lockdown Mode → EKM → TLS Bypass → Compliance API 存取
- OpenAI Trust Portal 證據整理：ISO 證書、SOC 2 Type 2、安全白皮書、DPA
- Workspace Header 注入：ChatGPT-Allowed-Workspace-Id，限制核准工作區
- EKM（Enterprise Key Management）：客戶 KMS 管理主金鑰，保護靜態資料
- Lockdown Mode：限制網頁瀏覽/Agent 模式降低提示注入風險
- Secure MCP Tunnel：企業環境 MCP 安全連線
- 20 項控制與資料驗證情境清單
